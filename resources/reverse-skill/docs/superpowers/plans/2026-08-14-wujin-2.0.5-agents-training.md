# Wujin 2.0.5 AGENTS And Training Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify Windows `2.0.5` with exact paid Codex `AGENTS.md` replacement and a home-page training-document button.

**Architecture:** The owner template is a paid payload asset validated and written through the existing atomic Codex adapter transaction. The UI reuses the existing named `docs` link boundary, while the established version contract and release scripts produce the final portable EXE.

**Tech Stack:** Rust, Tauri, React/TypeScript, Node test runner, PowerShell release gates.

## Global Constraints

- Do not change the activation server, CDK device-binding policy, website, macOS package, or update publication.
- Preserve the original user `AGENTS.md` in the paid configuration backup and restore it on transaction failure or explicit environment restore.
- Do not accept arbitrary renderer URLs; use `tryOpenExternalLink("docs")`.
- The final artifact is a customer-facing portable single EXE with version `2.0.5`.
