# 免费工具助手页面重构设计

## 目标

重构“免费工具助手”页面的信息层级和选择流程，解决现有文字偏小、说明重复、目录失败后主体空白、操作区分散以及页面纵向过长的问题。保留现有 11 项能力、五个分类、全选/取消、逐项选择、安装、取消、进度、结果合并和失败重试语义，不改变免费模块与商业 CDK 的隔离边界。

## 信息架构

页面固定为四层，不再重复解释免费与付费能力：

1. **标题区**：`免费工具助手`、一句 14px 使用说明。
2. **概览与筛选区**：一个紧凑面板同时显示“永久免费”“已检测客户端数”“已选择数”，并提供分类筛选、全选和清空。
3. **能力区**：两列能力卡片；窄窗口降为一列。卡片展示图标、名称、单句用途、安装状态和选择框。
4. **固定动作区**：内容区底部固定安装按钮和当前阻断原因。进度开始后在同一位置替换为进度条、当前能力/客户端和取消按钮，避免页面跳动。

删除现有绿色免费声明、免费/付费双栏说明、独立状态条和底部重复提示。侧边栏“一键配置”已经承担商业能力入口，不在免费页重复宣传。

## 视觉与排版

- 沿用 2.0 白底、浅灰边框和单一粉红主操作色，不新增高饱和装饰或持续位移动画。
- 页面标题保持 24px；能力名称、筛选标签和主要状态使用 14px；正文与按钮使用 13px；辅助状态最低 12px。
- 能力卡片使用稳定最小高度，选中态只改变边框、浅色背景和复选框，不改变尺寸。
- 两列网格的卡片内容顺序保持现有固定能力顺序；分类筛选只隐藏非当前分类，不重排选中项。
- 加载、空目录、失败和安装阶段共用同一稳定内容槽位，避免错误横幅插入后推动整页。
- 继续支持 `prefers-reduced-motion`、键盘焦点和完整复选框标签。

## 状态行为

### 目录加载成功

- 默认展示“全部”分类和 11 张能力卡片。
- 分类切换不清除选择。
- “全选”只选择当前目录中的全部能力；“清空”移除全部选择。
- 安装按钮文案包含数量：`安装已选 3 项能力`。

### 目录加载中或失败

- 首次加载时在能力槽位显示骨架占位，工具栏保持稳定尺寸。
- 无目录且失败时显示居中的错误面板和唯一“重新加载”按钮，不再显示无效的全选工具栏或大块空白。
- 已有目录后的刷新失败保留旧目录和用户选择，只在概览面板显示轻量错误与重试入口。

### 安装进行中

- 锁定筛选、卡片和批量选择。
- 固定动作区显示当前能力、当前客户端、`completed / total`、稳定宽度进度条和取消按钮。
- 取消只发送一次；取消请求失败后恢复按钮并显示可重试状态。

### 安装完成

- 保留当前分类和选择，合并各客户端结果。
- 卡片只显示聚合状态；详细路径和备份继续留在运行记录，不在卡片底部堆叠。
- 部分失败时安装按钮变为 `重试未完成项`，成功项不重复安装。

## 组件边界

- `FreeSkillsPage` 负责页面组合，不直接实现筛选或进度状态机。
- `app-state.ts` 增加 `freeSkillCategoryFilter`，并提供纯函数完成筛选、全选和重试项计算。
- 页面内部拆分轻量组件：`FreeSkillOverview`、`FreeSkillGrid`、`FreeSkillActionDock`；不引入通用表单框架。
- Rust/Tauri 免费 Skill IPC 契约保持不变。

## 测试与验收

1. 11 项能力固定顺序、五分类筛选和选择保持。
2. 页面不再出现重复免费/付费说明；正文没有小于 12px 的字号。
3. 目录失败时只有一个稳定错误面板和一个重试入口，没有空白工具栏。
4. 两列到一列的响应式布局不溢出 1120×720 固定窗口。
5. 安装前、安装中、取消中、完成和部分失败时动作区高度稳定。
6. 键盘、复选框标签、焦点样式和 reduced-motion 回归通过。
7. UI 全量测试、TypeScript 和 Vite build 通过。

## 非目标

- 不改变 11 项能力内容、来源、许可证或安装后端。
- 不把免费功能绑定 CDK。
- 不在本切片加入能力搜索、收藏、在线商店或远程目录。
- 不生成正式发布包，不更新线上 manifest 或官网。
