# 1.1.0 激活页视觉增强设计

## 背景与目标

优化 `launcher/app/qml/App.qml` 的激活页和窗口品牌识别，同时保持现有 CDK 验签、缓存和正式构建流程不变。目标是让测试人员能清楚看到品牌、购买入口和激活结果，并让 7 天/永久卡片具有轻微、稳定的动态镭射光效。

## 范围

包含：

- “查看完整文档”按钮改为红色主按钮。
- 7 天和永久 CDK 购买卡片分别使用对应的渐变主题和轻量动态光带。
- 使用用户提供的 `brand-gradient.svg` 替换窗口左上角品牌图标。
- “立即激活”操作后显示成功或失败的模态确认窗口。

不包含：

- 不改变 CDK token 格式、Ed25519 验签、公钥或缓存结构。
- 不改变正式包的开发模式禁用规则。
- 不把验签逻辑移动到 QML；QML 只消费 `installer.activate()` 的结果。

## 视觉设计

### 文档按钮

将破甲说明页的“查看完整文档”设置为现有 `AppButton` 的 `primary: true`，使用当前品牌红色和白色文字。链接仍由 `installer.openLink("docs")` 处理。

### 购买卡片

继续复用 `PurchaseCard`，增加每张卡片的渐变配置和动画光带：

- 7 天卡片：红、橙、粉的低饱和渐变，突出体验和行动感。
- 永久卡片：红、紫、蓝的渐变，突出长期授权和高级感。
- 卡片内部增加裁剪的半透明斜向光带，缓慢循环横向移动；动画透明度保持较低，避免干扰文字。
- 鼠标悬停时增强边框和光带，但不改变卡片尺寸和布局。
- 未配置购买链接时保留现有禁用状态，并降低光效透明度或停止动画。

实现只使用 QML `Gradient`、`Rectangle` 和 `NumberAnimation`，避免 `ShaderEffect` 带来的显卡兼容性和打包风险。

### 品牌图标

将 `C:\Users\Anything001\OneDrive\桌面\brand-gradient.svg` 复制为 `launcher/app/resources/brand-gradient.svg`，窗口标题栏左侧 `Image.source` 改为该资源。保持 24×24 的现有尺寸和 `PreserveAspectFit`，不改变窗口布局。

## 激活结果交互

在 `App.qml` 中增加一个居中的模态 `Popup`：

- 成功：绿色视觉状态、标题“激活成功”、说明可继续配置。
- 失败：红色视觉状态、标题“激活失败”、说明检查 CDK 后重试。
- 弹窗由“立即激活”按钮统一触发，无论成功或失败都显示。
- 空输入在 QML 层直接显示失败提示，不调用服务层、不写入缓存。
- 非空输入继续调用 `installer.activate(cdk.text)`；服务层仍是 CDK 真伪和缓存写入的唯一决定者。
- 确认按钮关闭弹窗；成功时不自动跳页，保留用户当前激活页上下文。

开发模式下非空输入仍按现有开发预览逻辑返回成功；空输入仍显示失败弹窗，便于预览两种界面状态。正式冻结包的验签行为不变。

## 测试与验收

- 静态 UI 测试确认文档按钮为主按钮、品牌资源路径正确、两张卡片包含动画光带配置。
- UI 流测试确认空输入失败弹窗和成功/失败弹窗文案存在。
- 运行完整 `unittest` 套件，既有 CDK、桥接和布局测试全部通过。
- 启动开发模式，确认 QML 根对象创建且 SVG 能加载。
- 不重新生成正式 EXE，直到 UI 变更完成并通过测试；正式打包仍使用版本化文件名和正式公钥。

## 兼容性与风险

- 光效动画只在卡片链接可用时运行，减少无效 UI 动画。
- SVG 作为普通资源打包，不引入新的运行时依赖。
- 激活弹窗不读取或显示完整 CDK，避免泄露授权内容。
- 所有既有授权核心代码保持不变，确保历史正式 CDK 不受影响。
