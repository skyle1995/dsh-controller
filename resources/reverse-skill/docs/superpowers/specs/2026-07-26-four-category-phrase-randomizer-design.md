# 四分类话术随机选择器设计

## 目标

将 `C:\Users\Anything001\Downloads\200条.txt` 中的 200 条话术导入现有话术选择器，并按四种性格分别展示和随机抽取。

## 数据结构

页面内维护四个分类，每类严格包含 50 条话术：

1. 技术极客 / 资深玩家型
2. 小白围观 / 疑惑求助型
3. 热心分享 / 推荐推荐型
4. 吃瓜吐槽 / 轻松幽默型

TXT 中的分类标题、分隔线和序号只用于解析，不进入复制文本。话术正文保持原样。

## 界面与交互

- 页面顶部增加四个分类标签，沿用现有深色与橙色强调视觉。
- 首次打开默认选中“技术极客”。
- 切换分类后，仅渲染当前分类的 50 条话术。
- 计数显示当前分类数量与总数量，例如 `50 / 200 条`。
- 随机按钮仅从当前分类中抽取一句。
- 同一分类内连续随机时，避免立即重复上一句。
- 随机命中后自动高亮卡片、滚动到卡片并复制正文。
- 点击任意卡片继续支持直接复制。
- 切换分类后清除旧分类的选中态，并为该分类维护独立的上次随机索引。

## 实现边界

- 保持单文件 HTML，不引入框架、构建步骤或外部资源。
- 保留现有剪贴板主路径与 `document.execCommand('copy')` 回退路径。
- 保留移动端安全区和响应式布局。
- 不改写或润色 TXT 中的话术正文。

## 验证标准

- 页面内恰好有 4 个分类、每类 50 条、总计 200 条。
- 四个分类标签均可切换，列表与计数同步更新。
- 随机结果始终属于当前分类。
- 当前分类条目超过一条时，连续两次随机结果不同。
- 卡片点击和随机按钮均触发复制流程。
- HTML 可直接本地打开，控制台无语法错误。
