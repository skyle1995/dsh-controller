# Wujin 2.0.2 Pj2 Web Auditor Design

## Goal

Add the useful Pj2 prompt behavior to the CDK-gated Codex configuration as one
offline paid Skill without replacing GPT-5.6 v45, NERV, the selected add-on, or
the single `model_instructions_file` contract.

## Selected Content

- Preserve the web asset audit state machine: network baseline, execution-flow
  tracing, AST clarification, CDP telemetry, and parity verification.
- Preserve the evidence precedence and concise evidence-reporting discipline.
- Package the result as `web-asset-auditor/SKILL.md` with one routing entry.

## Excluded Content

- Pj2 executables, backups, icons, screenshots, extraction output, and Resource
  Hacker tooling.
- The Python `config.toml` writer and its `gpt-5.4` defaults.
- Generic prompt text already covered by GPT-5.6 v45, NERV, or the selected
  paid add-on.
- Any second `model_instructions_file` or additional MCP registration.

## Asset Contract

The new root is `assets/codex/ayanami-web-auditor`. It contains a strict source
record, provenance evidence, deterministic file manifest, routing file, and one
Skill. The source record pins the SHA-256 and size of the user-provided Pj2
source script and executable but does not package either original artifact.

Every packaged file is size- and SHA-256-verified before any user file is
written. Missing, malformed, path-traversing, reordered, or modified records
fail closed.

## Runtime Integration

The Codex adapter validates the new asset after v45, NERV, and the existing
add-on. It appends the new routing path to the existing managed `AGENTS.md`
block. `config.toml` continues to point only to the current combined v45/NERV
instructions file, and the existing three MCP tables remain unchanged.

All writes continue through `AtomicFileTransaction`; validation failure occurs
before `AGENTS.md` or `config.toml` is modified.

## Verification

- A dedicated PowerShell supply-chain test checks provenance, allowlists,
  manifest integrity, payload inclusion, and free-bundle isolation.
- Rust adapter tests prove successful routing and fail-closed behavior for
  missing/tampered auditor assets.
- Release-contract tests require the asset in paid payloads.
- The full automated gate runs the new supply-chain test and the existing
  Python, Rust, UI, TypeScript, and Vite suites.

## Release Boundary

This change updates source assets and gates only. It does not build, sign,
upload, or publish a 2.0.2 executable or update manifest.
