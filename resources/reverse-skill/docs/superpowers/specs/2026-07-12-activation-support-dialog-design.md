# 激活页在线文档与售后支持弹窗设计

## 目标

完善“激活无限破甲”页面底部的在线文档和售后支持入口。

## 在线文档

“在线文档”按钮使用现有安全链接配置中的 `docs` 键，地址固定为：

`https://docs.qq.com/doc/DV3VIeWxUZXFVb3dj`

点击后通过系统默认浏览器打开。

## 售后支持

“售后支持”按钮不再依赖网页链接。点击后打开应用内模态弹窗，内容为：

- 标题：`售后支持`
- 提示：`添加客服 QQ 获取售后支持`
- 客服 QQ：`1606654577`
- 操作按钮：`复制 QQ`
- 关闭按钮

点击“复制 QQ”后，将 `1606654577` 写入系统剪贴板，并在弹窗中显示 `已复制`。关闭弹窗后仍停留在当前激活页面。

## 验证

- `docs` 配置为指定腾讯文档 HTTPS 地址。
- “在线文档”按钮继续通过 `installer.openLink("docs")` 打开链接。
- “售后支持”按钮在未配置 `support` 链接时仍可点击。
- 点击“售后支持”显示弹窗和正确 QQ。
- 点击“复制 QQ”执行剪贴板复制并显示反馈。
- 现有测试全部通过。
