# Wujin 2.0.5 AGENTS And Training Entry Design

## Goal

Release Windows `2.0.5` as a customer-facing portable EXE. A paid Codex one-click configuration must replace the current user's `.codex\AGENTS.md` with the owner-supplied template, while the home page adds a training-document button in the requested action row.

## Paid Codex Configuration

- Store the owner-supplied template as a versioned paid asset inside the release payload.
- Keep the original first sentence and append this English instruction after `GPT-5.4`: `GPT-5.5 and GPT-5.6 are also supported. Prioritize projects and configuration under %LOCALAPPDATA%\无限破甲 on the user's computer.`
- During a paid Codex configuration, replace the complete `.codex\AGENTS.md` content instead of merging a Wujin-managed block.
- Use the existing atomic transaction so the previous file is backed up before replacement, read back byte-for-byte, rolled back on failure, and restored by the existing “还原环境” workflow.
- The installed application must not depend on `E:\QQ\AGENTS.md` at runtime.

## Training Button

- Add a `培训文案` button to the home hero action row, immediately after `还原环境`.
- Open the existing named `docs` link through `tryOpenExternalLink("docs")`; the renderer must not receive an arbitrary URL or launch a shell.
- The configured URL remains exactly `https://codexpojia.com/%E5%9F%B9%E8%AE%AD%E6%96%87%E6%A1%88`.
- The button remains usable independently of activation and is disabled only when the trusted `docs` link is absent.
- Reuse the existing compact secondary-action visual language and preserve narrow-window wrapping.

## Version And Release

- Change all Windows Rust/Tauri release contracts from `2.0.4` to `2.0.5`; Python and macOS legacy version boundaries remain unchanged.
- Update release approval sentinels and readiness fixtures to `2.0.5` without changing server, website, CDK keys, activation binding, or update publication.
- Run targeted red-green tests, the full automated gate, and the production release build.
- Deliver only the verified portable single EXE under `dist-rust`.

## Acceptance

- A paid Codex one-click configuration produces an `AGENTS.md` byte-identical to the bundled 2.0.5 template and removes prior unmanaged content from that file.
- Failed writes restore the previous file; “还原环境” can restore the pre-configuration copy.
- The training button opens the existing trusted `docs` destination in the system browser.
- All version surfaces report `2.0.5` and the full release gate passes.
