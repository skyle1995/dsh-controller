# Wujin v1.30.1 强化环境配置小白版竖向列表设计

## 目标

把现有“强化环境配置”卡片网格改成面向普通用户的单列竖向能力清单。页面包装要更有冲击力，但所有承诺必须真实：用户只需要选择想要的能力，软件自动适配已检测到的受支持智能助手，不要求用户理解技能编号、仓库、路径或安装机制。

## 固定边界

- 页面标题继续使用“强化环境配置”。
- 保留“无需激活 · 可选安装”“全选”“取消全选”“安装选中的强化能力”等既有操作契约。
- 页面文案、能力名称、按钮、状态、提示和无障碍标签全部使用简体中文，不展示英文技能名、英文简介、技能编号、仓库、提交号或技术路径。
- 内部仍使用原有 11 个技能编号、分类、安装命令、进度事件和结果状态；本次不修改 Rust、Tauri、免费资源包、付费配置、激活逻辑或更新逻辑。
- 不出现购买、付费、解锁全部、代码仓库、外部工具或技术框架宣传。
- 第三方智能助手只在需要区分安装结果时使用中文名称；原始英文名称不直接渲染。
- 原始安装路径、备份路径和后端英文错误保留在运行日志中；本页面只显示小白可理解的中文结果摘要。

## 页面包装

页头保持“环境强化”小标签和“强化环境配置”主标题，主说明改为：

> 给你的智能助手，一次装上 11 项实用本领。不会设置也没关系，选中需要的能力，剩下的全部交给软件。

状态条继续显示“无需激活 · 可选安装”，兼容数量改成：

> 已找到 N 个可以强化的智能助手

主操作旁的默认提示改成：

> 选好后点击安装，软件会自动完成全部设置

## 竖向列表结构

五个中文分类保持现有顺序。每个分类内部使用单列列表，不再根据窗口宽度生成多列网格。每一项从左到右包含：

1. 两位数字序号，例如“01”。
2. 中文能力名称和一句面向结果的用途说明。
3. 中文安装状态，例如“尚未安装”“已完成 2 个智能助手”。
4. 选择框及“选择”提示。

整行均可点击。未选择时为白底细边框；悬停时出现红色强调；选中时使用浅红背景、红色边框和轻微阴影。忙碌期间整行降低透明度并禁止修改选择。列表保持正文可滚动，不改变固定窗口尺寸。

## 状态与结果中文化

- 进度标题使用“正在强化的能力”和“正在处理的智能助手”，不再显示英文技术称呼。
- 六类客户端名称映射为“克劳德助手”“代码助手”“基罗助手”“光标助手”“编程助手”“风帆助手”。
- 卡片聚合状态把“客户端”改成“智能助手”。
- 结果区标题改为“强化结果”。存在目标时显示“已自动完成安装”，存在备份时显示“已创建安全备份”；不显示原始路径。
- 后端原始详情不直接渲染。根据状态展示固定中文说明；精确错误和路径仍可在“运行日志”页面查看。
- 目录加载和安装失败使用中文通用提示，并保留“重新加载目录”或重新选择能力的恢复入口。

## 无障碍与响应式要求

- 每个选择框的无障碍名称使用中文页面名称。
- 现有键盘选择、焦点可见、忙碌禁用、进度播报和减少动态效果规则继续保留。
- 单列布局在宽窗口和窄窗口下都保持单列；窄窗口只调整行内元素的换行方式。
- 页面源码可以保留内部英文标识和类型名，但真实渲染文案不得泄漏目录中的英文名称、英文简介、客户端英文名称或后端英文错误。

## 测试与验收

- 先新增失败测试，证明当前页面仍是多列网格、仍渲染目录英文名称/简介，并包含“当前 Skill”等英文文案。
- 源码测试验证精确页头文案、11 项中文名称、11 项中文说明、单列列表类名以及禁止技术宣传的边界。
- 真实组件测试使用英文目录和英文客户端夹具，进入“强化环境配置”后断言用户可见内容只出现中文映射，不出现原始英文名称、简介、客户端名和英文错误。
- 样式测试验证列表容器固定为纵向排列，条目具有序号、选中、悬停、禁用、焦点和减少动态效果状态。
- 完整 UI 回归、类型检查和前端构建必须通过。
- 自动化通过后重新启动本机 Debug 客户端，由主人在真实窗口确认文案冲击力、单列密度、滚动长度和小白可理解程度。

## 不在本次范围

- 不改变 11 项能力来源、资源包内容、安装顺序、冲突处理、取消、回滚或付费隔离。
- 不修改其他页面的品牌英文名称。
- 不出包、不签名、不制作安装器、不发布网站清单或上传可执行文件。
