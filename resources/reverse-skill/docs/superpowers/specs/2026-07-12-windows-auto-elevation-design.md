# Windows EXE 自动管理员启动设计

## 目标

正式 Windows EXE 启动时自动检查管理员权限。若当前权限不足，触发 UAC，并以管理员身份重新启动同一个程序。

## 适用范围

- 仅对打包后的 Windows EXE 启用自动提权。
- `python -m launcher.app.main --development` 开发预览不触发提权。
- 非 Windows 环境不执行 Windows 权限检查。

## 启动流程

1. 应用在创建 Qt 窗口前检查当前进程是否具有管理员权限。
2. 已是管理员时，继续正常启动。
3. 不是管理员时，调用 Windows `ShellExecuteW`，使用 `runas` 动作重新启动当前 EXE，并保留原启动参数。
4. 成功发起管理员进程后，当前非管理员进程立即退出，避免出现两个窗口。
5. 用户取消 UAC 或系统无法发起提权时，显示明确错误消息，然后退出，不进入主界面。

## 安全与循环控制

重新启动后的进程再次检查权限；只有检查结果为管理员时才进入主界面。提权失败不会反复重新启动，因此不会形成启动循环。

## 验证

- 管理员进程直接进入应用。
- 非管理员正式 EXE 使用 `runas` 发起提权并退出原进程。
- 原始命令行参数被完整传递。
- 用户取消或调用失败时显示错误并退出。
- 开发预览跳过提权。
- 现有测试全部通过。
