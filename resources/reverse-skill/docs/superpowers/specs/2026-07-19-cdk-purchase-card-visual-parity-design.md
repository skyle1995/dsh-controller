# Rust 激活页 CDK 购买卡片视觉对齐设计

## 目标

让 Rust/React 激活页中的“7天激活 CDK”和“永久激活 CDK”卡片恢复 Python/QML 版本的视觉语言，同时保留现有外链点击、禁用态和固定窗口布局。此次只改视觉层，不改变 CDK 验证、链接地址或导航状态。

## 现状与基准

旧版 `launcher/app/qml/App.qml` 的 `PurchaseCard` 已定义基准：

- 卡片内部为浅色面板，外层为 1px 渐变描边；
- 顶部有 3px 渐变强调线；
- 斜向半透明光带持续扫过，悬停时增强；
- 标题 14px、描述与购买提示 11px；
- 链接不可用时透明度约为 0.52，且不可点击。

Rust 版当前使用整块高饱和渐变背景，缺少旧版的描边、内层面板和可控的镭射层，因此视觉重量和层次与 Python 版不一致。

## 设计方案

### 结构

保持现有 React `PurchaseCard` DOM 和 `onClick` 逻辑，在独立的 `purchase-cards.css` 中使用 CSS 伪元素与现有 `.laser` 子元素实现：

1. `.purchase-card::before`：渐变边框，通过 `padding-box`/`border-box` 叠层实现 1px 描边；
2. `.purchase-card::after`：顶部 3px 渐变强调线；
3. `.purchase-card .laser`：斜向、低透明度、无限循环的镭射光带；
4. 内容层保持相对定位，确保文字始终在光带之上。

### 色板

- 7天卡：`#ff6a5f → #ff9f43`；悬停增强边框与光带，不改变文字可读性；
- 永久卡：`#f0445d → #8158e8`；悬停增强边框与光带；
- 卡片表面：使用白色/浅灰半透明面板，避免整块高饱和填充；
- 禁用态：沿用交互样式的低透明度和 `not-allowed` 光标。

### 动效与交互

- 镭射光带 6.2 秒一轮，从左上向右下斜向扫过；
- 普通态透明度低，悬停态提高到可感知但不遮挡文字；
- `prefers-reduced-motion: reduce` 时停止动画并保留静态渐变；
- `:hover`、`:active`、`:focus-visible` 与现有按钮状态保持一致，不引入新的导航行为。

## 验收标准

- 两张卡片均存在渐变边框和顶部渐变线；
- 两张卡片均存在镭射层和循环动画，且支持减少动效设置；
- 文字字号与 QML 基准一致；
- 链接可用时点击仍调用原有 `openLink`，不可用时仍禁用；
- UI 回归测试覆盖色板、边框、光带、动画和 reduced-motion 规则；
- `npm test` 与 TypeScript 检查通过，Rust 核心行为不受影响。
