## 发布范围

- 刷新并固定 11 个免费 Skill；确定性 bundle 保持独立内容版本 `2.0.2`。
- 刷新 GPT-5.6/5.5 付费 add-on，并复核 V45、NERV、Web Auditor 供应链与免费隔离边界。
- 当旧 `device-identity.dpapi` 无法由当前 Windows 用户解密时，允许用户重新输入原 CDK 完成签名回执验证、旧设备解绑和单设备重新绑定。
- 首次提交 CDK 时才创建 identity；缺失 identity 与不可解密 identity 使用不同错误分类。
- 恢复操作使用跨实例 mutex、规范化路径、用户 SID、原 identity compare-before-promote 和 Windows no-follow 句柄。
- 新 identity 提升后保持稳定；网络或回执保存失败不会恢复旧 identity，避免服务器绑定与本地身份再次分裂。
- 回执保存完成前持续保护 license 根目录；启动分类不跟随 receipt 文件或父目录 reparse point。
- 应用版本、Tauri 版本、UI 版本和发布审批契约统一为 `2.0.3`。
