# 2026-07-28 无限破甲 Codex 换肤集成

## 场景

在 Tauri Windows 桌面应用中移植 Codex Desktop 换肤能力，同时保护正在进行的 Codex 会话。

## 可复用结论

1. 主题卡片点击只做预览，应用动作必须单独触发，避免误重启桌面客户端。
2. 生命周期层在停止进程前必须同时验证：Codex 根进程路径、CDP 监听归属和显式重启确认。
3. 自定义图片复制到应用自有目录并用 data URL 注入，可避开 `file://` 与页面 CSP 的兼容问题。
4. 上游资源使用固定提交、文件锁和逐文件哈希；运行时只接受回环 CDP 地址。
5. 真实桌面会话不可作为自动测试夹具；用模拟 HTTP/CDP WebSocket 覆盖注入与回读，真实环境仅做只读进程和端口检查。
