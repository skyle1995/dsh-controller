# 红队报告与复盘交付

交付物四件:**攻击路径图、证据链、风险清单、检测复盘**。
**红线:第三方(蓝队/客户)按报告步骤能复现每个关键节点**。

## 一、攻击路径图(一页讲清全程)

```
[外网打点]          [凭据/执行]         [内网横向]        [目标达成]
VPN CVE-2024-21887 → AiTM 钓 OWA 会话 → Responder 抓 hash → DCSync krbtgt
                                    ↘ Pod 逃逸 → 云控制台
```
- 每节点标:时间、资产、用的技能/漏洞编号、产物(会话/凭据文件)
- 用 mermaid/graphviz 出图,贴报告首页

## 二、证据链(每条结论三要素)

| 要素 | 说明 |
|---|---|
| 命令 | 原始命令(可直接复制执行) |
| 输出 | 关键回显片段(whoami/哈希前8位/时间戳) |
| 落档 | runs/ 下对应文件名 |

归档结构:
```
runs/
  <target>/
    01-recon/     # 指纹、端口
    02-exploit/   # 每个漏洞一个子目录(cmd.txt+output.log)
    03-creds/     # 凭据(脱敏后入报告,原文加密归档)
    04-lateral/   # 横向跳板记录
    05-loot/      # 外带数据清单+sha256
    timeline.md   # 全程时间线(与 SIEM 对时)
```

## 三、风险清单(按可利用性排序)

1. 【严重】边缘设备未修(CVE-xxxx,版本 x.y)→ 修复:升级至 z;临时:限制源IP
2. 【严重】域内 Kerberoastable 服务账户弱口令 → 修复:长随机密码+ gMSA
3. 【高】ADCS 模板配置(ESC1)→ 按 certipy find 输出逐条改
4. 【中】员工对 AiTM 钓鱼无分辨(点击率 x%)→ 建议:安全意识+硬件 MFA
5. 【中】内网 SMB 未签名 → 中继可行;签名策略下发

## 四、检测复盘(给蓝队的价值)

- 我们每步动作的**对应日志源**是否留痕(Security 4624/4688、Sysmon 1/3、EDR 告警)
- 时间线对照:动作时刻 vs 告警时刻(延迟/漏检)
- 漏检原因分类:规则缺失/日志未收/告警被忽略
- 给出优先补的 3 条检测规则(YARA/Sigma 示例)

## 五、模板结构

1. 摘要(一段话+路径图)
2. 范围与授权(ops/scope-contract 引用)
3. 攻击路径详述(每节点=证据链)
4. 风险清单
5. 检测复盘
6. 附录(工具与版本、原始日志索引)

## 红线(完成判定)
- 报告内每个"沦陷"结论都有三要素证据
- 路径图与时间线对齐无矛盾
- 风险条目全部给出可执行修复
